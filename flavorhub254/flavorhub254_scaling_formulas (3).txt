
flavorHUB254 – Developer Notes

==============================
🥣 1. Ingredient-Based Scaling (Flour as Anchor)
==============================

Used for: Cakes, Mandazi, Pies (any recipe where flour is the scaling anchor)

Formula:
    new_amount = base_amount * (user_flour / base_flour)

Example (Red Velvet Cake):
- Base Flour: 300g
- User selects 400g → scale factor = 1.33x
- Sugar (base 250g) becomes 333g

Adjustments allowed:
- Only one ingredient editable (e.g. flour)
- All other ingredients auto-scale
- Scaling should respect `min`, `max`, and `scaling_step` (e.g. step of 50g)

--------------------------------

==============================
🍽️ 2. Serving-Based Scaling
==============================

Used for: Stews, Curries, Soups, Fried Rice

Formula:
    new_amount = base_amount * (user_servings / base_servings)

Example (Coconut Ndengu Stew):
- Base Servings: 4
- User selects 6 → scale factor = 1.5x
- Ndengu (base 200g) becomes 300g

Behavior:
- Servings adjustable: true
- Ingredients are NOT manually editable
- UI shows smart rounded values

-------------------------------

✅ Summary of Logic

Scaling Anchor: Flour (for baking)
    → use flour ratio against base flour

Scaling Anchor: Servings (for stews, rice, soups)
    → use servings ratio against base servings

Recommended Additions in JSON:
- "editable_ingredients": true or false
- "adjustable_servings": true or false
- "scaling_step": 50 (to restrict UI to clean intervals)
- "min"/"max" per scaling anchor
